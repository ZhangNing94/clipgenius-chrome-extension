Privacy Policy - ClipGenius

Last Updated: May 25, 2026

Data Collection

ClipGenius processes webpage content to generate AI tags and summaries. All content extraction happens locally in your browser. The extension sends webpage text to DeepSeek API for AI processing. No personal data is stored on external servers.

Data Storage

Your saved clips, tags, and summaries are stored locally in your browser using Chrome's storage API. No data is synced to any external server. You can delete all data at any time.

Notion Integration

If you choose to export clips to Notion, content is sent directly from your browser to Notion's API. Your Notion API key is stored locally and never shared with any third party.

Third-Party Services

ClipGenius uses the following third-party services:

  • DeepSeek API — for AI tag and summary generation
  • Notion API — for optional Notion export (user-configured)
